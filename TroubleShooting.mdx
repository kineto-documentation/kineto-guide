---
title: "Troubleshooting"
description: "How to deal with problems"
---

**Kineto misunderstood my request**\
Try explaining it in more detail or upload a reference screenshot. If you're not satisfied with the results, you can always ask for help on our [Discord](https://discord.com/invite/WZqyuHtVQa).

**Kineto is stuck during code generation**\
Click **Stop** and resend your request. If that doesn't work, report the bug on [Discord](https://discord.com/invite/WZqyuHtVQa) with a link and screenshot.

**Ouch, there's an error!**\
Click **Try again**. If there’s no option to do so, contact support on [Discord](https://discord.com/invite/WZqyuHtVQa).

**A recent change broke the project**\
Visit **View history** (see the icon above the chat), select a previous version that worked well, and click **Restore**. Please note that if you edit a previous version, your current one will no longer be available!

**The preview screen is gray, but no error appears**\
This usually means that something went wrong during the final project build. Ask Kineto to make a small change, which often resolves the issue. If not, ask for help on [Discord](https://discord.com/invite/WZqyuHtVQa).
