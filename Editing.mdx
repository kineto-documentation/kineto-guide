---
title: "Editing "
description: "How to edit your app"
---

The main tool for making edits is the chat. Right in the chat, you can:

- Describe your ideas for new features
- Report bugs or interface issues
- Give instructions on how to change the website design

Also you may use **Metalayer window** in the chat for more precise changes\
With **Metalayer** you can:

- Edit the features of your app
- Make changes to design
- Manage user roles
- Manage the files you've added to your app

When app is finished and all desirable changes were made - it's time to [publish](https://docs.kineto.dev/Publishing) it!
