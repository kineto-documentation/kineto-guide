---
title: "Editing "
description: "How to edit your app"
---

The main tool for making changes is the chat. In the chat, you can:

- Describe your ideas of the new features
- Report bugs or interface issues
- Give instructions on how to change the website design

You can also use **Meta Layer** window in the chat for more precise changes\
\
With **Meta layer** you can:

- Edit the features of your app
- Make changes in the design
- Manage user roles
- Manage the files you've added to your app

When the app is finished and all desirable changes are made, it's time to [publish](https://docs.kineto.dev/Publishing) it!
